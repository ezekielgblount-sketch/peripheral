# Project setup and settings

## What you need

- **Unreal Engine 5.8** (the project was last opened with 5.8.4). Not a preview build, not Unity.
- macOS on Apple Silicon is the development machine (a 36 GB Mac). The project is kept Windows-ready: Blueprints and
  Python only, no C++, no Mac-only code.
- **Git LFS.** Every `.uasset` and `.umap` under `unreal/` is stored in LFS. Run `git lfs install` before cloning, or the
  assets arrive as tiny pointer files and the project will not open.
- Python 3 for the scripts that talk to the editor.

```bash
git lfs install
```

```bash
git clone https://github.com/UnoriginalComedian/peripheral.git
```

The project file is `unreal/Peripheral_POC/Peripheral_POC.uproject`.

Not in the repo (ignored): `Builds/` (packaged apps), `SourceArt/` (generated textures and audio sources),
`Reference/private/` (Joel's family-home photos, never committed), and Unreal's `Saved/`, `Intermediate/`,
`DerivedDataCache/`, `Binaries/`.

## Plugins (from `Peripheral_POC.uproject`)

| Plugin | Why |
|---|---|
| ModelContextProtocol, AllToolsets, EditorToolset | Lets a Claude model drive the editor (the Unreal MCP server on `localhost:8000`) |
| PythonScriptPlugin, EditorScriptingUtilities | The build scripts run inside the editor |
| GeometryScripting, ModelingToolsEditorMode (editor only) | Every mesh in the game is generated by code |
| MoverExamples | Supplies the motion-captured walk, idle and crouch animations |
| MetaHumanCharacter (editor only) | Building Jack as a MetaHuman |

MetaHuman also needs the **MetaHuman Creator Core Data**, which is an install option on the engine itself: Epic Games
Launcher → Unreal Engine → Library → the down arrow beside Launch on the 5.8 tile → Options → tick it → Apply (5.8 GB).
The cloud rigging step needs an Epic sign-in approved in a browser; once approved it is remembered.

## Player settings (the in-game Settings menu)

Saved in a save file (slot `settings`, class `BP_SaveSettings`) and applied at start-up.

- **Display:** window mode (windowed, borderless, full screen), resolution (1280x720 to 3840x2160; default 1600x900),
  V-sync, frame rate cap (30, 60, 120, unlimited), field of view (70 to 110).
- **Graphics:** overall preset (Low, Medium, High, Epic, Custom) and separate shadows, global illumination, reflections,
  textures, effects, post-processing, anti-aliasing; resolution scale 50 to 100% (default 100).
- **Audio:** master, music, sound effects, ambience.
- **Controls:** mouse sensitivity, invert Y, rebinding for walk, strafe, use, crouch, flashlight.
- **Accessibility:** camera motion intensity, unease effect intensity cap, subtitles.
- **Footage look:** preset and six sliders. Values in [02_LOOK_AND_FEEL.md](02_LOOK_AND_FEEL.md).

Progress is a second save file (slot `progress`): the last day reached.

## Controls

| Key | Does |
|---|---|
| W A S D, mouse | Walk, look |
| E | Use, pick up, carry, push (mower, bin, broom), put down, switch a lamp |
| C | Crouch |
| F | Flashlight |
| Esc | Pause; frees the mouse |

Test keys: 1 to 9, 0 and minus set the unease level; F1 shows the unease bar; F5 starts a chore day with random changes
(works from the title screen without the menu); F6 lists what has changed; N day / night; L the corridor loop test;
H lets Jack's shadow stop copying him; B and M head bob and camera motion.

## Running the editor from scripts

All from `unreal/Peripheral_POC`:

```bash
Scripts/editor.sh start
```

```bash
python3 Scripts/uepy.py path/to/script.py 300
```

- `Scripts/editor.sh start|stop|restart` starts the editor in the background with the MCP server on, without taking
  focus. It only ever touches the editor it started for this project.
- `python3 Scripts/uepy.py <file> [timeout]` or `-c "<code>"` runs Python inside the open editor and prints its output.
- `Scripts/mem_check.sh` prints the editor's memory use. Restart the editor above about 12 GB; MetaHuman builds and big
  blueprint writes push it to 17 GB or more.
- `python3 Scripts/shot.py <out_dir> name:x,y,z:tx,ty,tz ...` takes pictures from the editor viewport (camera position,
  then the point it looks at, in the blueprint coordinates described in [04_HOW_ITS_BUILT.md](04_HOW_ITS_BUILT.md)).

## Testing without playing by hand

- Start and stop play mode from Python: `unreal.get_editor_subsystem(unreal.LevelEditorSubsystem).editor_request_begin_play()`
  and `editor_request_end_play()`.
- `Scripts/pd.sh <step> [VAR=value ...]` drives the playing game: `req REQ=2` starts Day 2, `go GO=x,y,z LOOK=x,y,z`
  moves the test pawn, `use`, `hold`, `drop`.
- `python3 Scripts/story_test.py [first_day]` plays the five-day story end to end by script and prints the state after
  each day.
- `python3 Scripts/fit_check.py` walks the player capsule through every doorway, hall and stair.

Script tests press "use" through test hooks. They do not prove that a person can click a button or that something is
visible on screen. See the menu bug in [05_CURRENT_STATE.md](05_CURRENT_STATE.md) for what that cost.

## Packaging the Mac app

Close the editor first (memory), then:

```bash
Scripts/package_mac.sh
```

The log is `Saved/Logs/package_mac.log`; look for `BUILD SUCCESSFUL` and `exit 0`. The app lands in
`Builds/Mac/Peripheral_POC.app`. The Desktop shortcut "Play Peripheral" on Joel's Mac opens
`Builds/Peripheral_Demo_live_menu.app`, so move the old one aside and move the new one to that name. The first launch
pauses about 15 seconds for shaders, then opens in a 1600x900 window. An incremental package takes about two minutes;
a full one about ten.

## Rules on Joel's Mac

- Never move or focus his windows. Never launch the packaged game while he is using the machine unless he asks: it grabs
  the mouse even in the background. Test in editor play mode instead.
- Watch memory. No more than two heavy jobs at once.
- Do not delete; move old things aside.
- Never commit secrets, `.env` files, or `Reference/private/`.
